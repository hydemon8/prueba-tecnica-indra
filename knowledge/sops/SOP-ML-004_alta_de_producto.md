# SOP-ML-004 — Alta de un producto nuevo (SKU)

## 1. Material mínimo
Vistas del producto sobre el plato giratorio, con la misma cámara e iluminación de la línea. Mínimo 36 vistas
(una cada 10°); recomendado 72 (una cada 5°). El hueco angular máximo entre vistas consecutivas no puede superar
30°: con huecos mayores el ángulo no se certifica y el robot no actuará sobre ese producto.

## 2. Entorno controlado
El producto se incorpora primero en staging, nunca directamente en producción.

## 3. Verificación
Se valida con vistas no usadas como referencia. Criterio de aceptación: al menos el 99,5 % de las acciones del
robot dentro de ±10°, y ninguna confusión con productos existentes del catálogo.

## 4. Paso a producción
Requiere aprobación de calidad o del gerente de planta (SOP-OPS-005). Quien solicita no puede aprobar.
